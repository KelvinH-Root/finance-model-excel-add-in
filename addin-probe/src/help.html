HFG Probe

A throwaway add-in that tests what Office.js can do in real Excel before the HFG add-in is built. It belongs to the hfg-models repo (folder addin-probe); the README there explains how to run it.

Open the HFG Model tab in Excel and choose Open probe in the Probe group. Use a blank workbook or a copy, never a live model. Clean up removes everything the probe adds.
